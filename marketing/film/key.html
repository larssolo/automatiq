Get your free
Gemini API key.

It takes about a minute. TextFox can then write texts for you.

01

Open Google AI Studio

Go to aistudio.google.com and sign in with your Google account.

02

Create an API key

On the API keys page, click Create API key. Google makes a new project for it.

03

Copy the key

It starts with AIza. Keep it private, like a password.

04

Paste it in TextFox

Settings → AI · Gemini. Paste the key, tap Test key, then Save.
